**Git** — это бесплатный инструмент управления версиями с открытым исходным кодом. Вы устанавливаете его один раз, а затем запускаете команды `git` в любой папке, которую вы хотите отслеживать.

Папка, отслеживаемая Git, называется **репозиторием** (или сокращенно **репо**). Внутри этой папки Git записывает снимки ваших файлов каждый раз, когда вы сохраняете контрольную точку.

Вы всегда взаимодействуете с Git через терминал:

```bash
git --version
```

Эта команда выводит установленную версию Git и подтверждает, что Git доступен в вашей системе. Если она возвращает ошибку, значит Git не установлен.

Каждая команда, которую вы изучите в этом разделе, начинается со слова `git`, за которым следует подкоманда, такая как `init`, `status` или `commit`.
