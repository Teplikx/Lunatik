Папка `.git` — это место, где Git хранит всё: каждый коммит, каждую ветку, вашу конфигурацию и указатели на текущее состояние репозитория.

Вы почти никогда ничего не редактируете внутри `.git` напрямую. Команды Git изменяют его за вас. Но полезно знать, что там находится:

```bash
ls .git
```

Вы увидите такие записи, как:

- `HEAD`: небольшой файл, указывающий на текущую ветку
- `config`: настройки для этого конкретного репозитория

- `objects/`: база данных всех снимков и содержимого
- `refs/`: указатели на ветки и теги

Если вы когда-нибудь удалите папку `.git`, проект перестанет быть репозиторием Git. Сами файлы останутся, но вся история будет удалена.

## Подсказки ##
Выполните `git init -b main`, чтобы инициализировать репозиторий с `main` в качестве ветки по умолчанию.

Затем выполните `cat .git/HEAD`, чтобы вывести содержимое файла. Добавьте `-q` к `git init` чтобы подавить его вывод.
