Самой часто используемой командой Git, безусловно, является `git status`. Она сообщает о текущем состоянии вашего репозитория: какие файлы были изменены, какие подготовлены к фиксации, а какие еще не отслеживаются.

```bash
git status
```

В только что инициализированном репозитории без файлов вывод выглядит следующим образом:

```bash
On branch mainNo commits yetnothing to commit (create/copy files and use "git add" to track)
```

После добавления файлов `git status` выделит их в разделе **Untracked files**. По мере создания коммитов команда показывает, какие файлы были изменены, подготовлены к фиксации или не имеют изменений.

Для компактного и удобного для машинной обработки вида используйте краткую форму:

```bash
git status --short
```

Это выводит по одной строке для каждого измененного файла с двухбуквенным кодом, объясняющим его состояние (мы рассмотрим эти коды в следующей главе).
