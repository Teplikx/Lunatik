Каждый коммит подписывается именем и адресом электронной почты. Прежде чем вы сможете сделать свой первый коммит, Git должен знать, кто вы. Вы настраиваете это один раз, глобально, с помощью `git config`:

```bash
git config --global user.name "Ada Lovelace"git config --global user.email "ada@example.com"
```

Флаг `--global` означает, что настройка применяется ко всем репозиториям на вашем компьютере. Без него настройка применяется только к текущему репозиторию.

Вы можете прочитать значение настройки с помощью той же команды, опустив само значение:

```bash
git config --global user.nameAda Lovelace
```

Имя и адрес электронной почты отображаются рядом с каждым сделанным вами коммитом, поэтому используйте те данные, которые вы готовы опубликовать.
