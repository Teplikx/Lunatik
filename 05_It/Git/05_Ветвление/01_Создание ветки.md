Чтобы создать новую ветку, используйте `git branch`, указав после неё нужное имя:

```bash
git branch feature-login
```

Это создает новую ветку, указывающую на текущий коммит. Это **не** переключает на неё. Вы остаётесь на той ветке, на которой находились, но теперь в том же месте существует новый указатель.

Просмотр списка веток подтверждает, что новая ветка была создана:

```bash
git branch  feature-login* main
```

Имена веток по общепринятым правилам пишутся в нижнем регистре и используют дефисы между словами. Распространенные шаблоны включают `feature-x`, `fix-bug-123` и `experiment-y`.
