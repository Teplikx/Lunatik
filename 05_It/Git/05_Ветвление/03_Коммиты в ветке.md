Коммиты, которые вы делаете в ветке, влияют только на эту ветку. Ветка `main` остается именно там, где она была, нетронутой, пока вы не решите выполнить слияние.

Это основная идея тематических веток: пробуйте что-то в стороне, оставляя `main` стабильной.

```bash
git switch -c feature-loginecho "login form" >> app.txtgit add app.txtgit commit -m "Start login form"
```

Теперь `feature-login` имеет один дополнительный коммит, в то время как `main` остается без изменений. Вы можете переключиться обратно в любое время, и рабочие файлы вернутся к версии `main`:

```bash
git switch maincat app.txt    # исходное содержимое, без строки "login form"
```

Ветки — это независимые временные шкалы до тех пор, пока вы не объедините их снова.
