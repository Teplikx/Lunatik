Создание ветки и переход в неё — это два отдельных действия. Современная команда для переключения — `git switch`:

```bash
git switch feature-login
```

Если вы хотите создать и переключиться за один шаг, используйте флаг `-c` («create»):

```bash
git switch -c feature-login
```

Это наиболее распространенный рабочий процесс при начале новой работы.

Вы также можете встретить `git checkout` в старых руководствах. Она делает то же самое и до сих пор работает:

```bash
git checkout feature-logingit checkout -b feature-login   # создать и переключиться
```

Чтобы узнать, на какой ветке вы сейчас находитесь, выполните `git branch --show-current`:

```bash
git branch --show-currentfeature-login
```
