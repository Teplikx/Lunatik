Когда ветка больше не нужна (например, работа была объединена или эксперимент был заброшен), удалите её с помощью флага `-d`:

```bash
git branch -d feature-login
```

Git отказывается удалять ветку, содержащую неслитые коммиты. Это проверка безопасности; она предотвращает случайную потерю работы.

Если вы действительно хотите отбросить ветку и её коммиты, принудительно удалите её с помощью `-D`:

```bash
git branch -D feature-login
```

Вы не можете удалить ветку, на которой сейчас находитесь. Сначала переключитесь на другую ветку, а затем удалите:

```bash
git switch maingit branch -d feature-login
```

Удаление ветки удаляет указатель, а не сами коммиты. До тех пор, пока другая ветка или тег по-прежнему ссылаются на эти коммиты, они остаются в репозитории.
