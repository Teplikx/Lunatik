**Ветка** в Git — это просто перемещаемый указатель на коммит. Ветка по умолчанию обычно называется `main`, и каждый создаваемый вами коммит продвигает этот указатель вперед.

Ветки позволяют работать над разными линиями разработки одновременно, не мешая друг другу. Вы можете:

- Опробовать рискованную идею в побочной ветке и без последствий отказаться от неё
- Разрабатывать новую функциональность изолированно, пока `main` остается стабильной
- Передать работу коллеге, поделившись веткой

Вы можете вывести список веток в любое время с помощью:

```bash
git branch
```

Ветка, на которой вы сейчас находитесь, отмечена символом `*` рядом с её названием. Внутренне Git отслеживает «текущую ветку» через файл `.git/HEAD`, который вы видели ранее.
