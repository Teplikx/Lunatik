После того как изменения проиндексированы, вы сохраняете их в репозиторий с помощью `git commit`. Каждому коммиту требуется короткое сообщение, описывающее внесенные изменения.

```bash
git commit -m "Add welcome message"
```

Флаг `-m` (сокращение от _message_) позволяет написать сообщение прямо в командной строке. Без него Git откроет редактор и будет ждать, пока вы его введете.

Хорошие сообщения коммитов — короткие, конкретные и написаны в повелительном наклонении, подобно командам, которые вы даете кодовой базе:

- `Fix login redirect bug`
- `Add dark mode toggle`
- `Update README with install steps`

После выполнения коммита `git status` сообщает о чистом рабочем дереве, а проиндексированные изменения теперь являются частью постоянной истории репозитория.
