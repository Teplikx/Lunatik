Как только файл был закоммичен, Git начинает его отслеживать. В следующий раз, когда вы его отредактируете, `git status` покажет его как **modified**, а не как неотслеживаемый.

```bash
git status --short M hello.txt
```

Буква `M` во втором столбце означает «изменено в рабочем каталоге, но еще не проиндексировано». Вы индексируете изменения с помощью той же команды `git add`:

```bash
git add hello.txtgit status --shortM  hello.txt
```

Обратите внимание, что `M` переместилась в первый столбец. Эти два столбца — **область подготовленных файлов (staged)** (слева) и **рабочий каталог (working directory)** (справа). После того как изменения подготовлены, вы фиксируете их так же, как и любые другие:

```bash
git commit -m "Update hello.txt"
```

Каждый коммит сохраняет полный снимок состояния, поэтому вы не потеряете старую версию. Вы всегда можете к ней вернуться.
