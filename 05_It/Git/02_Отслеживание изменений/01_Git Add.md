Команда `git add` перемещает изменения в область подготовленных файлов (staging area). Вы указываете имя файла (или файлов), которые хотите подготовить:

```bash
git add hello.txt
```

Вы можете подготовить несколько файлов одновременно или использовать подстановочный знак:

```bash
git add file1.txt file2.txtgit add *.md
```

Или добавьте в индекс все изменения в текущей папке с помощью одной точки:

```bash
git add .
```

После индексации `git status --short` показывает файл с другим префиксом. Неотслеживаемые файлы использовали код `??`; новые файлы в индексе используют `A` (от _added_).

```bash
A  hello.txt
```

Файл теперь готов к включению в следующий коммит.
