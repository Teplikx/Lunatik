После того как вы создали коммиты, вы можете просматривать историю с помощью `git log`:

```bash
git log
```

Она показывает каждый коммит с его полным ID, автором, датой и сообщением, начиная с самых новых. Это слишком большой объем вывода для просмотра, поэтому большинство людей используют компактную форму:

```bash
git log --oneline
```

Это выводит по одной строке на каждый коммит: короткий ID, за которым следует тема:

```bash
a1b2c3d Add first task9f8e7d6 Add todo list
```

Полезные флаги включают:

- `-n 5`: показывать только последние 5 коммитов
- `--oneline`: компактный формат (одна строка на коммит)
- `--reverse`: изменить порядок на обратный, чтобы самый старый коммит отображался первым

Один только список тем часто является самым быстрым способом вспомнить, над чем вы работали.
