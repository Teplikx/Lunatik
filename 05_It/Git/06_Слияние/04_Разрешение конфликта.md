Отмена иногда является правильным решением, но в большинстве случаев вы на самом деле хотите **разрешить** конфликт и завершить слияние.

Разрешение конфликта — это ритуал из трех шагов:

1. Откройте файл с конфликтом. Замените блок маркеров версией, которую вы хотите оставить (или их комбинацией).
2. Подготовьте исправленный файл с помощью `git add`.
3. Завершите слияние с помощью `git commit`.

Вы можете использовать скрипт, чтобы напрямую перезаписать файл разрешенным содержимым, что вы и сделаете в этом уроке (редактор не потребуется).

Если вы забудете выполнить `git add` для разрешенного файла, коммит завершится ошибкой и сообщит вам, что файл все еще помечен как неразрешенный.
