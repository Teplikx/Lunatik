**Слияние** переносит работу из одной ветки в другую. После успешного слияния целевая ветка содержит все коммиты из обеих веток, а файлы отражают объединенный результат.

Стандартный рабочий процесс выглядит следующим образом:

1. Переключитесь на ветку, **в** которую вы хотите выполнить слияние (обычно `main`).
2. Выполните команду `git merge other-branch`.

```bash
git switch maingit merge feature-login
```

Git просматривает истории двух веток и определяет, как их объединить. В большинстве случаев это происходит автоматически. Два основных вида слияния (merge):

- **Fast-forward**: `main` не перемещалась с момента создания ветки. Git просто перемещает указатель `main` вперед.
- **Трёхстороннее слияние**: в обеих ветках появились новые коммиты. Git создает новый «merge commit», который объединяет их.
