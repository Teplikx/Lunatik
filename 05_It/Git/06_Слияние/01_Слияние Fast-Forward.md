Слияние типа **fast-forward** происходит, когда в целевой ветке нет собственных новых коммитов. Git может просто переместить указатель ветки вперёд, чтобы догнать изменения в побочной ветке.

Представьте, что `main` находится на коммите A. Вы создаете ветку, делаете коммиты B и C в `feature` и никогда не трогаете `main`. Когда вы переключаетесь обратно и выполняете слияние:

```bash
git switch maingit merge feature
```

Git замечает, что путь от A до C представляет собой прямую линию, поэтому он просто перемещает указатель `main` вперед к C. Новый коммит слияния не создается. История остается линейной.

Слияния типа fast-forward — это самый чистый результат, который вы можете получить. Они происходят автоматически, если за это время в целевой ветке не произошло никаких других изменений.
