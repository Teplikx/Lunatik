Git Show

`git show` отображает один коммит: его сообщение, метаданные и разницу (diff) внесённых им изменений. Без аргументов она показывает самый последний коммит:

```bash
git show
```

Вы также можете передать идентификатор конкретного коммита:

```bash
git show a1b2c3d
```

Или используйте относительную ссылку, такую как `HEAD~1`, чтобы обозначить «один коммит перед HEAD»:

```bash
git show HEAD~1
```

Чтобы получить только сообщение коммита (без diff), передайте `--no-patch` вместе со строкой формата:

```bash
git show --no-patch --pretty=%s HEAD
```

Это полезно в скриптах, где вас интересует только тема (subject line), а не всё содержимое.
