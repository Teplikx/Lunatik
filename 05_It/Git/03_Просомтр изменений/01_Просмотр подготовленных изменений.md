Как только вы проиндексируете изменения с помощью `git add`, обычная команда `git diff` перестает их показывать. Чтобы увидеть, что подготовлено для следующего коммита, используйте:

```bash
git diff --staged
```

(Флаг `--cached` является псевдонимом и выполняет те же действия.) Это то, что следует запускать непосредственно перед коммитом, чтобы еще раз проверить, что именно будет сохранено.

Эти две команды diff отвечают на два разных вопроса:

- `git diff`: «что я изменил, но ещё не добавил в индекс (staged)?»
- `git diff --staged`: «что попадёт в следующий коммит?»

Если у вас есть как неподготовленные, так и подготовленные изменения, эти две команды показывают разные наборы строк. Понимание того, что есть что, предотвращает фиксацию неверной версии.
