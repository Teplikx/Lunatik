`git diff` показывает вам, что именно изменилось в вашем рабочем каталоге с момента последнего коммита. Это одна из самых полезных команд, когда вы находитесь в процессе редактирования и хотите вспомнить, что именно вы сделали.

```bash
git diff
```

Строки, которые были удалены, начинаются с префикса `-`; добавленные строки начинаются с префикса `+`:

```diff
-print("hi")+print("hello")
```

По умолчанию `git diff` сравнивает рабочую директорию с тем, что было закоммичено в последний раз. Она **не** показывает изменения, которые уже проиндексированы. Запустите её перед добавлением в индекс, чтобы в последний раз проверить свои правки.

Неизмененные строки контекста вокруг ваших изменений отображаются с начальным пробелом, чтобы вы могли видеть, где именно в файле произошло изменение.
