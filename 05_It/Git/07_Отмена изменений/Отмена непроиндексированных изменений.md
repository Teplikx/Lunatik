Иногда вы вносите в рабочий каталог изменения, о которых сожалеете и которые хотите отменить. Пока изменения не были проиндексированы (staged), вы можете откатить файл к его зафиксированной версии с помощью:

```bash
git restore notes.txt
```

Это перезаписывает вашу рабочую копию `notes.txt` версией из последнего коммита. Вы потеряете свои несохраненные правки, но область подготовленных файлов (staging area) и история останутся без изменений.

Если вы хотите отменить все неиндексированные изменения в репозитории за один раз, используйте точку:

```bash
git restore .
```

`git restore` является деструктивной командой: всё, что вы не закоммитили (или не добавили в индекс), будет безвозвратно удалено после этого. Используйте её осознанно.
