Шаблоны внутри `.gitignore` следуют нескольким простым правилам:

- `secret.txt`: игнорировать файл с точным именем в любом месте репозитория
- `*.log`: игнорировать каждый файл, заканчивающийся на `.log`
- `build/`: игнорировать весь каталог `build` и всё его содержимое

- `logs/*.tmp`: игнорировать `.tmp` файлы только внутри `logs/`
- `#`: начинает строку комментария; игнорируется Git
- `!important.log`: исключение. Даже если предыдущее правило совпало с ним, этот файл **не** игнорируется

Порядок имеет значение, когда вы смешиваете правила и исключения. Более поздние шаблоны переопределяют более ранние для файлов, которым они оба соответствуют.

Важное предупреждение: `.gitignore` влияет только на те файлы, которые **еще не отслеживаются**. Если файл уже был зафиксирован (committed), добавление его в `.gitignore` не заставит Git прекратить его отслеживание. Сначала вам нужно будет удалить его из индекса.
