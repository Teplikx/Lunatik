Когда файл неожиданно появляется (или не появляется) в `git status`, бывает трудно понять, какое правило за это отвечает. Git предоставляет инструмент именно для этого:

```bash
git check-ignore -v build/output.txt
```

Если файл соответствует правилу игнорирования, Git выводит, какой файл и какая строка вызвали совпадение:

```bash
.gitignore:1:build/    build/output.txt
```

Если вы хотите получить ответ «да/нет» для одного пути, опустите флаг `-v`. Git завершает работу со статусом 0, если файл игнорируется, и 1, если нет, и выводит путь только при совпадении.

Для быстрого вывода списка «всех соответствующих файлов» вы можете использовать:

```bash
git check-ignore *
```

Это неоценимо для отладки сложных конфигураций `.gitignore` в реальных проектах.
