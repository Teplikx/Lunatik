Большинство реальных проектов создают файлы, которые вы не хотите хранить в системе контроля версий: результаты сборки, логи, секреты окружения, кэши редакторов и файлы, созданные инструментами.

Отслеживание этих файлов загромождало бы вывод каждой команды `git status`, раздувало бы репозиторий и создавало бы риск утечки конфиденциальных данных, таких как API-ключи.

Git решает эту проблему с помощью специального файла под названием `.gitignore`. Он находится в корне вашего репозитория и содержит список шаблонов, которые Git должен игнорировать.

```bash
node_modules/
.env
*.log
build/
```

Файлы, соответствующие любому шаблону в `.gitignore`, становятся невидимыми для Git: они не будут отображаться как неотслеживаемые, их нельзя будет подготовить к коммиту и они не будут зафиксированы.

Сам файл `.gitignore` обычно фиксируется в репозитории, чтобы у всех, кто работает над проектом, были одинаковые правила игнорирования.
