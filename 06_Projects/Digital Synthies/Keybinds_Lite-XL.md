Lite-XL - this god's and minimalistical code editor using in this project

### 1. Navigation

* **`Ctrl + Shift + P`** — **Command Palette** 
* **`Ctrl + P`** — **Quick Open** 
* **`Ctrl + F`** — **Find in current file**
* **`Ctrl + Shift + F`** — **Find in all project files**
* **`Ctrl + G`** — **Select line on number**
* **`Ctrl + \`** — **Show or hide main bar** 
* **`Ctrl + Enter`** — **Open folder** 

---

### 2. Editing and code 

-  **`Ctrl and arrows (UP/DOWN)`**  — change line positon to up/down
* **`Ctrl + D`** — Select current word
* **`Ctrl + L`** — Select current line
* **`Ctrl + Shift + D`** — Double line 
* **`Ctrl + Shift + K`** — Delete current line
* **`Ctrl + /`** — Comment current line
* **`Ctrl + Click` — Multi cursor

---

### 3. Window managment

* **`Ctrl + W`** — Kill current tab
* **`Ctrl + Tab` / `Ctrl + Shift + Tab**` — Change current tab
